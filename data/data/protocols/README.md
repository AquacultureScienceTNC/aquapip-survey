# Dry-weight protocols

Drop protocol files for **estimating dry tissue weight** into this folder
(`data/protocols/`). Any file placed here (PDF, DOCX, XLSX, etc.) automatically
appears as a download button in the Filtration Service Estimator, under
**"Protocols · estimating dry tissue weight."**

Until a file is added, the tool shows a greyed-out "coming soon" button — no code
change is needed to enable it; just commit a file here.

This `README.md` (and any `.gitkeep`) is ignored by the tool and will not appear
as a download.
